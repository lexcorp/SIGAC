# Install
Copy extension contents into repository root preserving paths. Do not overwrite existing AGENTS.md blindly.
1. Commit `.kiro/`, `.devin/`, `docs/agentic/`, ADR-0029.
2. Open repo in Kiro and verify AGENTS.md + steering.
3. Keep example hooks disabled until commands work locally.
4. Connect/index repo in Devin.
5. Create/pin Knowledge from `.devin/knowledge/*`.
6. Import `.devin.md` playbooks.
7. Run `docs/agentic/06-first-experiment.md`.
