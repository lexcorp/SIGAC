# 02 — Procedimientos

Contiene documentos derivados y resúmenes operacionales `[AS-IS]` destinados al análisis de SIGAC.

Fuente principal: **Guía de organización y manejo del expediente clínico**, complementada cuando corresponda por práctica observada. Estos documentos traducen el procedimiento normativo y operativo a una forma utilizable para análisis, pero no sustituyen la Guía original ni otras fuentes de mayor precedencia.

- `citas-programadas/`: procedimiento derivado de citas programadas.
- `solicitud-prestamo/`: procedimiento derivado de solicitud y préstamo de expedientes.
