# 05 — Notas operativas

Entrevistas, observaciones, consideraciones, pendientes e hipótesis. Su contenido debe tratarse como `[OPEN QUESTION]`, `[ASSUMPTION]` u observación hasta que una fuente de mayor precedencia o una decisión formal lo confirme.

- `entrevistas/`: testimonios y análisis derivados de entrevistas.
- `consideraciones/`: recomendaciones, ideas e hipótesis de trabajo.
- `NOTAS_DEPENDIENTES.txt`: pendientes operativos.

Estos artefactos no sobrescriben normativa, Guía, procedimientos oficiales, formatos ni evidencia operativa.
