# SEC-009 — Support for Documento de Seguridad

La ley mexicana vigente exige medidas administrativas, físicas y técnicas y actividades de gestión de seguridad. SIGAC deberá aportar insumos para el Documento de Seguridad institucional, por ejemplo:
- inventario de sistemas/datos;
- roles/accesos;
- controles técnicos;
- análisis de riesgos;
- bitácoras;
- incidentes;
- continuidad;
- respaldos;
- revisiones;
- capacitación relacionada.

SIGAC no “genera cumplimiento” automáticamente.
