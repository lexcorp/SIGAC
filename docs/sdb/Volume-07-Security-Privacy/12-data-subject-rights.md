# SEC-012 — Data Subject Rights Support

SIGAC deberá permitir, cuando la institución lo determine:
- localizar datos personales asociados a un titular;
- exportar evidencia necesaria para atender solicitudes;
- corregir datos maestros mediante proceso controlado;
- registrar restricciones/bloqueos cuando legalmente procedan;
- mantener trazabilidad de rectificaciones.

El sistema no decidirá por sí mismo procedencia de derechos ARCO.
