# SEC-008 — Privacy Roles

Roles institucionales a identificar:
- Responsable del tratamiento.
- Áreas que tratan datos.
- Encargados/proveedores, si existen.
- Comité/autoridad institucional competente.
- Administradores técnicos.
- Usuarios autorizados.

El software debe permitir evidenciar quién accede y bajo qué contexto, pero la designación jurídica pertenece a la institución.
