# SEC-002 — Security Principles

- least privilege;
- deny by default;
- explicit verification;
- defense in depth;
- secure by default;
- privacy by design/default;
- tenant isolation by design;
- no shared accounts;
- separation of duties where valuable;
- audit without over-logging sensitive data;
- short-lived credentials;
- reproducible hardened environments;
- assume external inputs are untrusted.
