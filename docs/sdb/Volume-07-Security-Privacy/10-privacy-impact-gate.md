# SEC-010 — Privacy Impact Assessment Gate

Antes de cambios que incrementen materialmente el tratamiento de datos, revisar necesidad de evaluación de impacto institucional.

Triggers candidatos:
- incorporar contenido clínico;
- biometría;
- RFID que permita rastreo más amplio;
- interoperabilidad masiva;
- analítica avanzada;
- IA sobre datos personales;
- nube externa;
- nuevas finalidades;
- nuevas transferencias de datos.

Resultado: Proceed / Mitigate / Formal PIA-DPIA required / Reject.
