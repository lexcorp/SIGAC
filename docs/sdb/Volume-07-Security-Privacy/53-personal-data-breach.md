# SEC-053 — Personal Data Breach Response

Security incidents involving personal data require a dedicated privacy assessment.

SIGAC should support capturing:
- event time;
- detection time;
- affected tenant;
- affected categories;
- approximate records;
- confidentiality/integrity/availability impact;
- containment;
- evidence;
- notifications/decisions by competent institutional authorities.

Notification duties and deadlines must follow the law/procedure applicable at incident time; the application must not hardcode legal conclusions.
