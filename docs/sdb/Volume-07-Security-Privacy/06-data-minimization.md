# SEC-006 — Data Minimization

Cada campo nuevo deberá responder:
1. ¿Qué caso de uso lo requiere?
2. ¿Qué norma/regla lo justifica?
3. ¿Quién necesita verlo?
4. ¿Cuánto tiempo debe conservarse?
5. ¿Puede derivarse sin persistir?
6. ¿Puede sustituirse por un identificador?

No agregar datos “por si acaso”.
