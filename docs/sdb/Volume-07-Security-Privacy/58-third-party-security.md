# SEC-058 — Third-Party / Processor Security

Before external hosting/support/integration:
- purpose and data scope;
- responsibility/processor role;
- access model;
- confidentiality;
- security controls;
- incident duties;
- data location;
- backups;
- subcontractors;
- termination/data return;
- audit/evidence rights where applicable.

Requires institutional/legal validation.
