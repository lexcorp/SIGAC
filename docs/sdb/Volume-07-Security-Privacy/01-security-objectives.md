# SEC-001 — Security Objectives

1. Evitar acceso no autorizado a datos de expedientes y trazabilidad.
2. Evitar acceso cruzado entre hospitales/tenants.
3. Preservar integridad de préstamos, devoluciones, custodia y auditoría.
4. Mantener disponibilidad durante operación clínica.
5. Detectar y responder a actividad anómala.
6. Reducir datos tratados al mínimo necesario.
7. Mantener evidencia de acciones críticas.
8. Recuperar datos y servicio tras fallas o incidentes.
