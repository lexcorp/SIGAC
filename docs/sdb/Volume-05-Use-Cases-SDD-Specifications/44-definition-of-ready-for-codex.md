# Definition of Ready for Codex

Una spec puede entregarse a Codex cuando:
- status = Approved for Implementation;
- no tiene OQ crítico sin resolver;
- actores y permisos críticos definidos;
- domain invariants referenciados;
- acceptance criteria completos;
- non-goals explícitos;
- dependencias conocidas;
- ADR técnicos requeridos disponibles;
- tests esperados definidos.
