# Exit Criteria — Volume 05

Listo para Volume 06 Architecture & ADR cuando:
- specs del MVP tienen boundaries claros;
- dependencias están identificadas;
- non-functional drivers se conocen;
- permisos críticos tienen resolución o decisión explícita pendiente;
- flujo de datos es suficientemente estable para diseñar arquitectura;
- no se requieren cambios estructurales al dominio por preguntas conocidas.
