# UC-018 — Consultar Situación del Expediente

## Read Model
- número;
- paciente mínimo;
- estado operativo;
- ubicación actual;
- custodia actual;
- préstamo activo;
- solicitud activa;
- incidencias;
- historial relevante.

## UX principle
Debe responder rápidamente: dónde está, quién lo tiene, desde cuándo y qué ocurrió.
