# SDD-002 — Spec Lifecycle

Draft
↓
Domain Review
↓
Business Review
↓
Compliance Review (cuando aplique)
↓
Approved for Implementation
↓
In Development
↓
Implemented
↓
Verified
↓
Released

## Change Rule
Una modificación a una regla aprobada requiere:
- cambio en spec;
- actualización de aceptación;
- actualización de pruebas;
- trazabilidad al cambio.
