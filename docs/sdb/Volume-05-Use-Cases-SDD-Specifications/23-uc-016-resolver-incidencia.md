# UC-016 — Resolver Incidencia

## Flujo
1. Abrir incidencia.
2. Registrar acciones de investigación.
3. Seleccionar resolución.
4. Capturar motivo/resultado.
5. IncidentResolved.
6. Mantener historial.

No se elimina la incidencia al resolverla.
