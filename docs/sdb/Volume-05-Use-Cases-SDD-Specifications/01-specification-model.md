# SDD-001 — Specification Model

Cada spec debe contener:

1. Problem / Intent
2. Scope
3. Actors
4. Preconditions
5. Inputs
6. Commands
7. Domain Rules
8. Main Flow
9. Alternate Flows
10. Exceptions
11. Domain Events
12. Read Models
13. Permissions
14. Data Requirements
15. Acceptance Criteria
16. Non-Goals
17. Traceability
18. Open Questions

## Identificadores
- UC-xxx — Use Case
- SPEC-xxx — Feature Specification
- AC-xxx — Acceptance Criterion
- FR-xxx — Functional Requirement
- BR-xxx — Business Rule
- SEC-xxx — Security Requirement
- OQ-xxx — Open Question
