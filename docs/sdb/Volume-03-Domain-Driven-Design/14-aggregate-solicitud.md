# DDD-014 — Aggregate Solicitud
Representa la necesidad autorizada de disponer de un expediente.
Datos: tipo/origen, expediente/paciente, fecha requerida, servicio, consultorio, médico/solicitante cuando aplique, prioridad, estado, asignado, timestamps.
Solicitud != Préstamo.
