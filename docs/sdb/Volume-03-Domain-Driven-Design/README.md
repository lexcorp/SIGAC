# Volume 03 — Domain-Driven Design
Este volumen propone el modelo DDD inicial de SIGAC.

**Expediente Clínico es el concepto central del dominio.** Movimiento explica su trayectoria; Solicitud expresa la necesidad; Préstamo formaliza custodia temporal; Ubicación responde dónde; Custodia responde quién; Incidencia representa desviaciones.

Los agregados e invariantes son propuestas de diseño, no afirmaciones normativas.
