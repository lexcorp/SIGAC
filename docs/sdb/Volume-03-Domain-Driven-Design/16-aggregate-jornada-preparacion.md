# DDD-016 — Aggregate JornadaPreparacion
Coordina expedientes requeridos para una fecha/turno/servicio.
Contiene ItemPreparacion.
Funciones: recibir agenda, crear ítems, detectar adiciones/cambios, marcar búsqueda/localización/preparación, agrupar por consultorio/especialidad y cerrar jornada.
