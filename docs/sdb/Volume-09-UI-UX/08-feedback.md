# UX-008 — Feedback

Toda acción debe comunicar:
- qué ocurrió;
- sobre qué expediente/recurso;
- estado resultante;
- siguiente acción útil.

Toast sólo para confirmaciones transitorias. Errores que requieren decisión permanecen visibles en contexto.
