# UX-004 — Accessibility

Target: WCAG 2.2 AA como objetivo de diseño.

- contraste suficiente;
- focus visible;
- navegación completa por teclado;
- labels explícitos;
- mensajes de error asociados al campo;
- estados no comunicados sólo por color;
- objetivos interactivos adecuados;
- soporte de zoom;
- orden de foco coherente;
- aria-live para feedback asíncrono relevante.
