# UX-002 — Operational Context

Usuarios principales:
- personal de Archivo Clínico;
- responsable/jefe de Archivo Clínico;
- personal solicitante autorizado;
- supervisión/auditoría;
- administración SIGAC.

El archivista puede trabajar con decenas o cientos de expedientes en una jornada. La UI debe favorecer escaneo visual, filtros, teclado, acciones contextuales y baja carga cognitiva.
