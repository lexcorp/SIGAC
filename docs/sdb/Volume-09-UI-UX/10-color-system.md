# VIS-002 — Color System

## Brand palette
| Token | Hex | Role |
|---|---|---|
| navy-900 | #1B3A65 | navegación, títulos, identidad |
| teal-500 | #4DB29E | acento/acción primaria |
| ice-200 | #D5E6F7 | superficies contextuales |
| cloud-050 | #F7FAFD | fondo general |
| white | #FFFFFF | surface |

## Extended blue
`#5DA3E8` candidato para información/selección, sujeto a contraste.

## Semantic colors
Brand colors != status colors.

Definir tokens independientes:
- success
- warning
- danger
- info
- neutral

Nunca usar sólo color para comunicar estado.
