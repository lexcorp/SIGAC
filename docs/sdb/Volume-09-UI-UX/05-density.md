# UX-005 — Operational Density

Tres densidades candidatas:
- Comfortable: formularios y detalle.
- Compact: tablas operativas por defecto.
- Dense: listas de alto volumen, opcional.

No reducir legibilidad para ganar filas. Las acciones secundarias se agrupan en menú contextual.
