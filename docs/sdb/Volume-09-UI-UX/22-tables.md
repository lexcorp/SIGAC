# DS-006 — Tables

Core operational component.

Features where justified:
- sticky header;
- sortable allow-list;
- filters;
- row selection;
- keyboard navigation;
- row actions;
- column visibility;
- density control;
- pagination/cursor;
- loading skeleton;
- empty/error state.

Never hide the primary identifier.
