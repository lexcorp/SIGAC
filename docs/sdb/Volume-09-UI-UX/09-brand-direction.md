# VIS-001 — Brand Direction

Personalidad:
- institucional;
- clínica;
- moderna;
- serena;
- precisa;
- no infantil;
- no excesivamente tecnológica.

Las formas orgánicas/circulares se reservan para superficies de marca. La operación utiliza geometría más sobria.
