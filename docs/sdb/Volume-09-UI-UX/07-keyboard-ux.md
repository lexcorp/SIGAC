# UX-007 — Keyboard-first

Atajos candidatos:
- `/` enfocar búsqueda universal.
- `g d` Dashboard.
- `g e` Expedientes.
- `g s` Solicitudes.
- `Esc` cerrar drawer/modal no destructivo.

No implementar shortcuts globales que interfieran con lector de pantalla o navegador sin evaluación.
