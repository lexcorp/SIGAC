# UX-001 — UX Principles

1. Work first: priorizar tareas accionables sobre métricas decorativas.
2. Expediente-centered: Expediente es el centro de comprensión operacional.
3. State-aware: toda acción depende del estado real del dominio.
4. Custody visible: ubicación y custodio deben ser evidentes.
5. Exception-driven: incidencias y vencimientos deben destacar sin saturar.
6. Progressive disclosure: mostrar primero lo necesario para decidir.
7. Fast retrieval: búsqueda global disponible desde cualquier módulo.
8. Safe actions: acciones irreversibles o sensibles requieren confirmación proporcional.
9. Traceable UX: toda acción crítica produce feedback y trazabilidad.
10. Accessible by default: no depender únicamente de color.
