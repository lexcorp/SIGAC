# Volume 09 — UI/UX & Design System

Este volumen convierte los casos de uso, permisos, workflows y contratos API de SIGAC en una experiencia operacional coherente.

## Objetivo
Diseñar una interfaz para Archivo Clínico que reduzca fricción, haga visible la custodia del expediente y permita saber con rapidez:

1. ¿Qué trabajo debo realizar ahora?
2. ¿Dónde está el expediente?
3. ¿Quién tiene la custodia?
4. ¿Por qué salió?
5. ¿Qué acción es válida en este estado?
6. ¿Qué incidencias requieren atención?

## Principio rector
SIGAC no es un dashboard de estadísticas. Es una herramienta de trabajo.

## Dirección visual
Inspiración suministrada por el proyecto:
- azul marino;
- azul clínico;
- turquesa;
- superficies blanco/azul muy claro;
- composición limpia, moderna y clínica;
- Poppins para identidad/títulos;
- Open Sans para interfaz/datos.

Las referencias son inspiración, no plantillas a copiar.
