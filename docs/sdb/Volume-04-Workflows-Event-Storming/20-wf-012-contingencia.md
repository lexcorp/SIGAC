# WF-012 — Contingencia

## Estado
Pendiente de definición institucional.

## Necesidad
La operación del archivo no puede detenerse si SIGAC no está disponible.

## Política candidata
1. Activar formato/control de contingencia.
2. Registrar mínimo: expediente, salida, custodio, destino, fecha/hora.
3. Operar temporalmente.
4. Al restablecer SIGAC, capturar/reconciliar movimientos.
5. Marcar registros como “capturados desde contingencia”.
6. Conservar evidencia original.
