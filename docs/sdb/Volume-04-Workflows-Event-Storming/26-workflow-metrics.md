# Workflow Metrics

- lead time Solicitud→Preparada;
- tiempo SearchStarted→Located;
- tiempo Prepared→Delivered;
- duración de custodia externa;
- duración de préstamo;
- tiempo ReturnReceived→Rearchived;
- % NoLocalizado;
- % citas tardías;
- % préstamos vencidos;
- % devoluciones con incidencia.

Estas métricas derivan de eventos, no de campos manuales aislados.
