# SIGAC Software Design Book — Volume 01: Foundation
Base documental del Sistema Integral de Gestión de Archivo Clínico.

## Método
SDD + DDD + Event Storming + ADR + Clean Architecture.

## Modelo de evidencia
NORMATIVA → PROCEDIMIENTO → AS-IS → TO-BE → DECISIÓN.

## Principio central
**Expediente Clínico es el concepto central del dominio.** Movimiento registra su trayectoria y aporta trazabilidad, pero no sustituye al Expediente.

## Fuentes base
Ley General de Archivos; NOM-004-SSA3-2012; Guía de organización y manejo del expediente clínico; entrevista/cuestionario de Jefatura de Archivo Clínico.
