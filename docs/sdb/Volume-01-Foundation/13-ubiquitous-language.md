# FND-013 — Ubiquitous Language
Expediente Clínico es el concepto central. Solicitud explica por qué se requiere. Preparación organiza disponibilidad. Préstamo formaliza salida. Movimiento explica trayectoria. Devolución formaliza retorno. Incidencia representa desviación. Ubicación responde dónde. Custodia responde quién.
## No equivalencias
Expediente != Movimiento; Solicitud != Préstamo; Ubicación != Custodia; Devuelto != Archivado; No localizado != Perdido.
