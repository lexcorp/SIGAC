# FND-005 — Objectives & KPIs
Objetivos: reducir tiempo de localización; elevar trazabilidad; digitalizar entregas/devoluciones; detectar vencidos; medir incidencias.
KPIs candidatos: tiempo medio/P95 de localización; % ubicación conocida; préstamos activos/vencidos; no localizados; preparados; entregados/regresados; incidencias y resolución.
Las metas requieren línea base formal.
