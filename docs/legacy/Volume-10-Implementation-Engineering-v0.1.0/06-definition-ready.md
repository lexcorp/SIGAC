# ENG-006 — Engineering Definition of Ready

Una tarea está lista para implementación cuando:
- spec aprobada;
- use case identificado;
- permisos definidos;
- API contract claro;
- open questions críticas resueltas;
- ADR necesarios aceptados;
- acceptance criteria disponibles.
